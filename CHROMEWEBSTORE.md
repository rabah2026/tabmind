**Detailed Description** [REQUIRED]
TabMind is a private, on-device AI sidebar assistant that interacts with your open browser tabs using local large language models. No cloud APIs, no subscriptions, and zero data leakage.

Transform how you browse, read, research, and work with tabs while keeping 100% of your data on your computer.

KEY FEATURES

• 100% Local & Private AI: Runs entirely on your hardware using your local AI runtime or Chrome's built-in on-device Prompt API. No text or browsing data ever leaves your machine.
• Smart Tab Context: Ask questions, get explanations, extract action items, or generate takeaways from your active tab or across all open tabs in your window.
• Context Continuity: Switch between tabs or select open tabs directly from the command dock. Clear centered context dividers keep track of your multi-tab research flow without losing conversation history.
• 40+ Built-in Chrome Skills: Instant one-click workflows across Understand, Research, Learning, Food & Recipes, and Fun categories.
• Custom Skill Creator: Build and save your own reusable custom AI prompts with distinct instructions.
• Rich Markdown & Formatted Tables: Responses render with headers, lists, code syntax blocks with one-click copy, and organized data comparison tables.
• One-Click Export: Download your conversation history as a clean, structured Markdown (.md) document anytime.
• Focused Dark Command Interface: High-contrast, keyboard-friendly sidebar interface built for distraction-free productivity.

HOW TO USE TABMIND

1. Open any webpage in Chrome.
2. Click the TabMind icon in your Chrome toolbar or press your extension shortcut to open the side panel.
3. Chat naturally with your tab, select a quick action tile, or trigger one of the 40+ skills from the skills menu.
4. Switch target tabs from the bottom context dock to cross-reference multiple pages in a single continuous thread.
5. Export your research summary to a Markdown file with a single click.

LOCAL ENGINES SUPPORTED

• Ollama: Native local integration with automatic installed-model detection.
• Chrome Built-in AI: Direct on-device inference using Chrome's built-in Prompt API.
• Local OpenAI-Compatible Endpoints: Connect to any local inference server running on localhost.

PRIVACY & DATA SAFETY

TabMind was built from day one on a strict zero-telemetry principle. It has no external analytics, no user tracking, no advertising, and no remote servers. All prompt processing happens locally on your computer.

**الوصف التفصيلي (Detailed Description)**
تطبيق TabMind هو مساعد ذكاء اصطناعي شخصي فائق السرعة يعمل في الشريط الجانبي لمتصفح كروم، ويتفاعل مباشرة مع صفحات الويب والتبويبات المفتوحة باستخدام نماذج لغوية محلية تعمل بنسبة 100% على جهازك الخاص. لا توجد أي خوادم سحابية، ولا اشتراكات مدفوعة، ولا مفاتيح API خارجية، مع ضمان تام لعدم تسريب أي جزء من بياناتك أو سجل تصفحك.

غيّر طريقتك في القراءة، والبحث، والعمل اليومي عبر الإنترنت مع الحفاظ الكامل على أمان وخصوصية بياناتك الشخصية.

الميزات الرئيسية:

• ذكاء اصطناعي محلي 100% وخصوصية مطلقة: يعمل بالكامل على موارد جهازك باستخدام المحرك المدمج في متصفح كروم (Chrome Built-in AI / Gemini Nano) أو عبر خوادمك المحلية المفضلة مثل Ollama و LM Studio. لا يغادر أي نص أو محتوى صفحة جهازك على الإطلاق.
• سياق التبويبات الذكي: اطرح الأسئلة، واستخرج النقاط الأساسية وجداول المقارنة، ولخص المقالات الطويلة، أو حلل أوراق البحث من التبويب النشط أو عبر جميع التبويبات المفتوحة بضغطة زر.
• استمرارية البحث وتتبع التبويبات: تنقّل بين صفحات الويب مع الحفاظ التام على سجل المحادثة. يُظهر التطبيق خطاً فاصلاً ذكياً عند تبديل التبويب حتى تظل أبحاثك متعددة المصادر مترابطة ومنظمة.
• أكثر من 40 مهارة جاهزة (Chrome Skills Catalog): أنجز مهامك بسرعة هائلة عبر الضغط على مفتاح (/) للوصول إلى مهارات متخصصة: الفهم والتلخيص، والبحث العلمي، والتعلم والبطاقات التعليمية، وصياغة الرسائل، واستخراج الإجراءات والمهام.
• إنشاء المهارات المخصصة: أنشئ واحفظ قوالب الأوامر والمهارات الخاصة بك لتكرار تنفيذها بلمسة واحدة.
• تنسيق Markdown وجداول مقارنة متقدمة: يعرض الردود مع عناوين منسقة، وقوائم، وكتل برمجية مزودة بزر نسخ سريع، وجداول بيانية منظمة.
• تصدير بنقرة واحدة: حمّل جلسة بحثك ومحادثتك بالكامل كملف Markdown منسق في أي وقت.
• واجهة عصرية داكنة ومريحة: تصميم جانبي متناسق وأنيق ينسجم مع واجهة كروم دون حجب صفحات الويب التي تتصفحها.

كيفية استخدام TABMIND:

1. افتح أي صفحة ويب في متصفح كروم.
2. انقر على أيقونة TabMind في شريط الأدوات أو افتح الشريط الجانبي (Side Panel).
3. تحدّث مع محتوى التبويب بشكل طبيعي، أو اضغط على مفتاح (/) لاختيار مهارة جاهزة مثل "التلخيص في جدول" أو "الشرح ببساطة".
4. بدّل بين التبويبات المفتوحة أو وجّه السؤال لجميع التبويبات من شريط السياق السفلي.
5. صدّر ملخص بحثك كملف Markdown بنقرة واحدة عند الانتهاء.

المحركات المحلية المدعومة:

• الذكاء الاصطناعي المدمج في كروم (Chrome Built-in AI - Gemini Nano): يعمل تلقائياً وبشكل فوري داخل المتصفح بدون أي إعدادات إضافية.
• Ollama: توافق محلي مباشر مع ميزة الاكتشاف التلقائي للنماذج المثبتة (Llama 3.2, Mistral, Qwen وغيرها).
• LM Studio ونقاط نهاية OpenAI المحلية: اتصال مباشر بأي خادم استدلال محلي يعمل على جهازك.

الأمان والخصوصية:

تم بناء TabMind من السطر البرمجي الأول على مبدأ الانعدام التام لجمع البيانات (Zero-Telemetry). لا توجد أدوات تتبع، ولا إعلانات، ولا اتصال بأي خوادم خارجية. جميع عمليات المعالجة تتم محلياً في ذاكرة جهازك.

## Permissions Justification

| Permission | Type | Justification |
| :--- | :--- | :--- |
| `sidePanel` | permissions | Required to render the assistant interface as a persistent Chrome side panel alongside open web pages without obstructing user browsing. |
| `tabs` | permissions | Required to access tab metadata (title, URL, favicon) so the user can see and select open tabs to supply context to the local AI. |
| `scripting` | permissions | Required to safely extract visible body text, headings, and user-highlighted excerpts from the active tab upon user prompt submission. |
| `storage` | permissions | Required to persist user settings (local AI provider, model names, max context size, custom skills) and tab chat history locally on device. |
| `<all_urls>` | host_permissions | Required to extract page text from web pages that the user requests assistance on across arbitrary domains. |
| `http://localhost/*` | host_permissions | Required to send local inference requests to local LLM servers (e.g. Ollama on port 11434, LM Studio on port 1234). |
| `http://127.0.0.1/*` | host_permissions | Required to send local inference requests to local loopback endpoints for on-device models. |
