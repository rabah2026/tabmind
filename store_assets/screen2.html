llama.cpp

Port of Facebook's LLaMA model in pure C/C++ with zero external dependencies. Highly optimized for Apple Silicon (Metal) and AVX2/AVX-512 on x86 architectures.

# Build with Apple Silicon Metal acceleration
cmake -B build -DGGML_METAL=ON && cmake --build build --config Release

# Run 4-bit quantized model locally
./build/bin/llama-cli -m ./models/7B/ggml-model-q4_k_m.gguf -p "Explain quantum computing"
