Prompt API with Gemini Nano in Chrome

Chrome includes Gemini Nano, an efficient on-device large language model designed to execute locally on desktop and laptop hardware without external API servers.

// Run on-device inference with zero network latency
const session = await window.ai.languageModel.create();
const stream = session.promptStreaming("Summarize this open tab...");
for await (const chunk of stream) {
  console.log(chunk); // Real-time tokens rendered 100% locally
}
